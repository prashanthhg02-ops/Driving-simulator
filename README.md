# Open Road — Driving Simulator

A lightweight, single-file driving game that runs in a modern web browser. Cruise a winding country highway, accelerate and brake, steer around traffic, and watch your speed and distance on the dashboard.

## Play

Open `index.html` in a modern browser and select **Start driving**. No installation or server is required.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Accelerate | `↑` or `W` | **GO** |
| Brake | `↓` or `S` | **BRAKE** |
| Steer | `←` / `→` or `A` / `D` | **←** / **→** |
| Start or restart | **Start driving** or `Space` | **Start driving** |

Avoid other cars and keep your car on the road. The game ends if you collide with traffic.

## Features

- Canvas-rendered highway, scenery, and traffic
- Live speed, gear, engine, and distance dashboard
- Keyboard and mobile touch controls
- Responsive layout for desktop and mobile
